# 內容來源說明

## 網站實際使用

- `site_template.html`：版面及一般雙語文案，`[[繁中||English]]` 會由產生器轉為語言欄位。
- `publications.html`：由改版前網頁完整保存的 37 筆卡片，保留原始姓名與內容供追溯。產生器清理學生姓名並提供翻譯。
- `all_links_and_media.json`：16 筆課程資源連結（15 個不同清單）與媒體資訊；課程連結全部顯示於網站。
- `scripts/build_site.py`：研究方向、文獻文字對應與課程中文名稱。

`index.html` 是上述來源產生的靜態檔案，不需在訪客瀏覽器中讀取本資料夾。

## 歷史整理資料

`01_homepage.md` 至 `05_gallery.md`、`publications_raw.txt` 是先前擷取整理，並非網站即時資料。保留供比對，不將其中宣稱直接視為已驗證事實。個人簡介、論文指標及課程標題仍需由維護者定期核對。

兩位只有中文姓名的學生（劉兆恆、林佩蓉）尚缺本人確認的英文拼寫；原始卡片保留姓名，公開頁面暫顯示英文姓名待確認，不自行音譯。
